# 云帆大学考试与成绩制度

## 考试纪律

- 学生须持学生证或校园卡进入考场，迟到 15 分钟以上不得入场，按旷考处理。
- 考试中携带手机等电子设备未按要求上交的，按作弊处理。
- 旷考课程成绩记零分且不得参加正常补考，只能重修。
- 考试作弊者，该课程成绩记零分，取消学位授予资格，视情节给予记过及以上处分。

## 成绩评定与绩点

课程总评成绩由平时成绩（30%-40%）与期末成绩（60%-70%）构成。成绩与绩点对照：

| 百分制成绩 | 绩点 |
|-----------|------|
| 90-100 | 4.0 |
| 85-89 | 3.7 |
| 82-84 | 3.3 |
| 78-81 | 3.0 |
| 75-77 | 2.7 |
| 72-74 | 2.3 |
| 68-71 | 2.0 |
| 64-67 | 1.5 |
| 60-63 | 1.0 |
| 60 以下 | 0 |

平均学分绩点（GPA）= Σ（课程学分 × 绩点）/ Σ（课程学分）。60 分为及格线，及格及以上取得该课程学分。

## 补考与重修

- 课程不及格（低于 60 分）者，可参加下学期开学第 1 周的补考，补考成绩按卷面记，最高记 60 分。
- 补考仍不及格或旷考、作弊者须重修。重修随下一年级跟班修读，或选重修班（选课人数达 20 人开班）。
- 重修成绩按实际成绩记载，不做覆盖，两次成绩均计入 GPA。
- 累计不及格学分达 15 学分者给予学业预警，达 25 学分者编入下一年级。

## 成绩复核

学生对成绩有异议，可在成绩公布后 5 个工作日内向开课学院教学办提交复核申请，由学院组织复核并在 10 个工作日内答复。
